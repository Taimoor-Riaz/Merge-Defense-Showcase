# Competitive Survival Merge Defense

**2D merge tower-defense for Android · Unity 6 (URP 2D) · 2026 · Client project**

A fast mobile tower-defense game where players build a deck of six units, summon them onto the board, and merge matching units into stronger ones to survive escalating waves and boss fights.

## What I built

- **Deck system** with a six-unit loadout chosen before each match
- **Summon and merge combat**, where combining identical units upgrades them on the battlefield
- **Wave and boss survival loop** with scaling difficulty
- **Pre-match global abilities** that players can activate during a run
- **Mobile-first performance** using Unity 6 and the 2D Universal Render Pipeline

## Tech stack

Unity 6 · C# · URP 2D · Android
